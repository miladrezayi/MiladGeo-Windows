# MiladGeo Windows

نسخه دسکتاپ MiladGeo بر پایه `index135.html`.

## ساخت خودکار با GitHub Actions

1. همه فایل‌های این پوشه را در ریشه Repository یعنی `MiladGeo-Windows` آپلود کن.
2. پوشه `.github/workflows` را هم همراه فایل‌ها آپلود کن.
3. بعد از Push، GitHub Actions پروژه را روی Windows Runner می‌سازد.
4. خروجی Build از بخش Actions > Artifacts قابل دریافت است.

> فایل `index.html` همان نسخه پایه پروژه است و در این بسته تغییر محتوایی داده نشده است.
