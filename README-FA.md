# MiladGeo Windows — Milad win v17

نسخه v17 بر پایه Milad win v16 ساخته شده است.

## تغییرات v17
- در منوی **5 — AREA / POLYGON** بخش **IMPORT PENZD FROM EXCEL** اضافه شد.
- فایل‌های Excel با فرمت `.xlsx` و `.xls` و همچنین CSV قابل خواندن هستند.
- ترتیب PENZD: `Point / Easting(X) / Northing(Y) / Z / Description`.
- اگر ردیف عنوان داشته باشد، ستون‌ها با نام‌های رایج تشخیص داده می‌شوند؛ بدون عنوان، پنج ستون اول به‌ترتیب PENZD خوانده می‌شوند.
- تمام نقاط معتبر X/Y فایل به ترتیب ردیف‌ها به‌عنوان رأس‌های پلیگون در نظر گرفته می‌شوند.
- با یک کلیک، نقاط وارد شده و مساحت پلیگون با روش Shoelace محاسبه می‌شود.
- تعداد نقاط، مساحت و محیط در نتیجه نمایش داده می‌شود.
- سایر امکانات نسخه v16 حفظ شده‌اند، از جمله Graphic Map با محیط مشکی سبک CAD/AutoCAD.
