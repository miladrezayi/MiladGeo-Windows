# Miladwin V29

مبنا: Miladwin V28

تغییر اصلی:
- Excel و ورود دستی POINT از یک MAIN POINT LIST مشترک استفاده می‌کنند.
- Import تکراری Excel دیگر نقطه را با نام جدید مثل P001_2 نمی‌سازد.
- نقطه‌ای که Point Number یکسان یا مختصات X/Y/Z یکسان داشته باشد، دوباره اضافه نمی‌شود.
- ورود دستی POINT نیز از ایجاد Point Number یا مختصات تکراری جلوگیری می‌کند.
- Area همان وضعیت V28 را حفظ کرده و بخش Excel آن اضافه نشده است.
